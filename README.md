# Dungeon Dodge

**Dungeon Dodge** ist ein kleines 2D-Arcade-Spiel in Python mit Pygame.  
Der Spieler sammelt Münzen, weicht Gegnern aus und versucht, möglichst lange zu überleben.

Dieses Projekt wurde als Arbeitsprobe für eine Bewerbung im Bereich Game Development erstellt.

## Features

- Spielerbewegung mit WASD oder Pfeiltasten
- Gegner verfolgen den Spieler
- Münzen erscheinen zufällig auf dem Spielfeld
- Score-System
- Levelsystem mit steigender Schwierigkeit
- Game-Over-Bildschirm
- Neustart per Tastendruck
- Saubere, verständliche Python-Struktur

## Technologien

- Python 3
- Pygame

## Installation

```bash
pip install -r requirements.txt
```

## Spiel starten

```bash
python main.py
```

## Steuerung

| Taste | Aktion |
|---|---|
| WASD / Pfeiltasten | Spieler bewegen |
| R | Neustart nach Game Over |
| ESC | Spiel beenden |
